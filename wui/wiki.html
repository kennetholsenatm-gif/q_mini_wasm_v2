Quantum-inspired ternary AI inference engine with GF(3) arithmetic, stabilizer tableau simulation, and graph-native QGNN architecture.

Quick Start

cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build
./build/q_mini_wasm_v2

QGNN Architecture

The Quantum Graph Neural Network uses stabilizer tableau representation for O(n²) scaling instead of exponential state vectors.

  • GraphTableau: O(n²) Pauli operator tracking
  • Tropical routing: Max-plus semiring for MoE
  • SYCL acceleration: GPU/FPGA compute

Forward-Forward Training

Gradient-free local learning using tropical inner products and Hebbian updates.

// Two-pass training
positive_goodness = tropical_inner_product(activations)
negative_goodness = tropical_inner_product(corrupted_activations)
hebbian_update(weights, positive_goodness, negative_goodness)
