Dashboard Config Training Wiki Glossary

Core Terms

GF(3) Math
Galois Field of order 3. Finite field with elements {-1, 0, +1} for ternary arithmetic. All operations mod 3.
Qutrit Physics
Three-level quantum system (ternary qubit). States |0⟩, |1⟩, |2⟩ or {-1, 0, +1} in balanced ternary.
Stabilizer Tableau Math
Matrix representation of stabilizer states. Enables O(n²) simulation vs O(3ⁿ) state vectors.
Forward-Forward ML
Gradient-free learning using local goodness metrics. Two forward passes: positive and negative samples.
Tropical Inner Product Math
Max-plus semiring: addition→max, multiplication→add. Preserves polyhedral geometry.
Hebbian Update ML
"Neurons that fire together wire together." Weight updates based on correlated activation.
MoE Arch
Mixture of Experts. 243-expert routing using tropical (max-plus) algebra for selection.
QGNN Arch
Quantum Graph Neural Network. Graph-native message passing over ternary-weighted edges.
SYCL HW
Standard C++ for heterogeneous computing. GPU/FPGA parallel execution.
USM HW
Unified Shared Memory. Zero-copy host/device memory access.
Trit Math
Ternary digit. Three states: -1, 0, +1. 5 trits pack into 8 bits.
Clifford Gates Physics
H, S, CSUM gates. Preserve stabilizer formalism, O(n²) simulable.
