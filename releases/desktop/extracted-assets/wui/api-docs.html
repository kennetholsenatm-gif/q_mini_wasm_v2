Graph

Core QGNN graph-native data structure for quantum-inspired neural networks.

class Graph { public: Graph(size_t nodes, size_t experts); void add_expert(size_t id, size_t spec_dim); void create_entanglement_pattern(); RouteResult route(const std::vector<Trit>& input); void set_energy_target(double target_pj); PerformanceMetrics get_metrics() const; };

Constructors

Graph(size_t nodes, size_t experts)
Create a new QGNN graph with specified number of nodes and experts.

Methods

add_expert (size_t id, size_t spec_dim) -> void
Add an expert node with specified ID and specialization dimension.
create_entanglement_pattern () -> void
Create quantum entanglement patterns between expert nodes.
route (const std::vector<Trit>& input) -> RouteResult
Route input through the QGNN graph and return results.
set_energy_target (double target_pj) -> void
Set energy efficiency target in pJ/op.
get_metrics () -> PerformanceMetrics
Get current performance metrics.
Returns
RouteResult contains output vector, latency (μs), energy (pJ/op), and accuracy (0-1).
Example Usage
// Create QGNN graph
auto graph = Graph(1000, 64);

// Add expert nodes
for (size_t i = 0; i < 64; i++) {
    graph.add_expert(i, 16);
}

// Create entanglement
graph.create_entanglement_pattern();

// Route input
std::vector<Trit> input = {1, 0, -1, 1, 0};
auto result = graph.route(input);

std::cout << "Latency: " << result.latency_us << " μs" << std::endl;
std::cout << "Energy: " << result.energy_pj << " pJ/op" << std::endl;
Notes
- Graph complexity is O(E) where E is number of edges, not O(N²)
- Energy targets are enforced through ternary operations
- All operations maintain GF(3) compliance
- Thread-safe for concurrent routing operations
